# Võ Đài Thần Ngư (PVP Arena) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 1vs1 Sumo PVP Arena triggered by the `pvp` chat command, where two fish duel in the pond's center while all other fish circle around forming a spectator arena, culminating in the winner devouring the loser and claiming the "👑 Vua Hồ Cá" crown.

**Architecture:** Introduce `PvpArenaManager` to drive the state machine (`idle` -> `summon` -> `fighting` -> `knockout`). Integrate with `School` to override steering (duelist collision vs. spectator orbital circling) and handle the eating sequence on defeat. Expose arena state to `LiveOverlay` for visual effects (glowing arena ring, tug-of-war meter, King's crown badge).

**Tech Stack:** TypeScript, Three.js, React 19, Vitest, Vite

## Global Constraints

- Preserve all existing comments and docstrings unrelated to this change.
- Keep the `Fish Username Visibility Timer` working seamlessly with the arena.
- Retain full compatibility with the existing Tu Tiên and Thiên Kiếp mechanics.
- All unit tests and Vite production build must pass without errors.

- [ ] **Step 2: Write unit tests in `src/pvp-arena-manager.test.ts`**

```typescript
import { describe, expect, it } from "vitest";
import { PvpArenaManager } from "./pvp-arena-manager";
import { School } from "./school";

describe("PvpArenaManager", () => {
  it("initializes in idle phase with no fighters", () => {
    const arena = new PvpArenaManager();
    expect(arena.state.phase).toBe("idle");
    expect(arena.state.fighter1).toBeNull();
    expect(arena.state.fighter2).toBeNull();
  });

  it("queues first challenger when registered", () => {
    const arena = new PvpArenaManager();
    const joined = arena.registerChallenger("user1", "Alice", "alice.png");
    expect(joined).toBe(true);
    expect(arena.state.waitingChallenger?.id).toBe("user1");
    expect(arena.state.phase).toBe("idle");
  });

  it("starts summon phase when second challenger joins", () => {
    const arena = new PvpArenaManager();
    arena.registerChallenger("user1", "Alice", "alice.png");
    const started = arena.registerChallenger("user2", "Bob", "bob.png");

    expect(started).toBe(true);
    expect(arena.state.phase).toBe("summon");
    expect(arena.state.fighter1?.id).toBe("user1");
    expect(arena.state.fighter2?.id).toBe("user2");
    expect(arena.state.waitingChallenger).toBeNull();
  });

  it("transitions from summon to fighting after countdown", () => {
    const arena = new PvpArenaManager();
    arena.registerChallenger("user1", "Alice", "alice.png");
    arena.registerChallenger("user2", "Bob", "bob.png");

    const school = new School();
    arena.update(3.1, school);
    expect(arena.state.phase).toBe("fighting");
  });

  it("boosts cheer power for specific fighter", () => {
    const arena = new PvpArenaManager();
    arena.registerChallenger("user1", "Alice", "alice.png");
    arena.registerChallenger("user2", "Bob", "bob.png");

    arena.addCheerPower("Alice", 10);
    expect(arena.state.fighter1?.score).toBe(10);
    expect(arena.state.fighter2?.score).toBe(0);
  });
});
```
